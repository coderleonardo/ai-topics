## CRUD and HTTP

**CRUD**
- C(reate): add new rows to the database
- R(ead): retrieve information from a database
- U(pdate): modify data in the database
- D(elete): remove data from the database

**HTTP Protocol** has similar functions:
- POST: used to send information from the client to the server
- GET: used to get information from the server
- PUT: used to update information in the server requested by the client
- DELETE: used to delete a given resource
